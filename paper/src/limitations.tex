We evaluate two systems at single versions, zero-shot, on public English-dominant data with synthetic class mixes. Absolute accuracies carry a $\pm$5\pp{} wording band, and gate savings depend on production base rates that we do not observe. Latency was measured from two client sites and on two hardware types only. Safety and PII gold labels involve LLM annotators whose policies differ from dataset conventions (72.8\% agreement). The LLM reference receives a necessarily different prompt format and is not a paired competitor. The \laya{} fine-tuning path is untested.
