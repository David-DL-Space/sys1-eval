\section{Data Construction Details}\label{app:data}
%=====================================================================
\paragraph{A (routing).} RouterBench 0-shot rows. Cheap model \texttt{mistral-7b-chat}, strong model \texttt{gpt-4-1106-preview}. The 200 cheap and 200 strong items are stratified by source benchmark. The state is the raw request, truncated to 1,500 characters. Options: \emph{cheap} = ``a small fast 7B chat model is enough to answer correctly''; \emph{strong} = ``only a frontier model will answer correctly''.
\paragraph{B / B2 (tool selection).} 400 BFCL \texttt{simple}/\texttt{live\_simple} requests with exactly one gold function, and 80 per $K$. Option descriptions are truncated to 110 characters. The state lists the request and numbered tools. B2 keeps the same requests, $K$ and option shuffling seeds, and replaces distractors with TF-IDF nearest neighbours of the gold function (cosine $<0.8$, different base name).
\paragraph{C (guardrail).} 150 relevant requests with their gold function; 150 \texttt{irrelevance}/\texttt{live\_irrelevance} requests with up to 6 of their listed functions.
\paragraph{D (RAG).} SciFact, NFCorpus, FiQA, SciDocs and CQADupStack-android. 800 qrels positives, 800 BM25 hard negatives (token Jaccard $\leq0.6$ to the positive), 320 random negatives. Passages p50 = 172 words. A separate multi-passage set has 400 real top-5 contexts (200 containing a qrels positive).
\paragraph{E/G (injection).} Attacks come from deepset/prompt-injections and jackhhao/jailbreak-classification \citep{deepset2023injections,jackhhao2023jailbreak}. Benign texts were filtered to exclude imperative or role-play text. In G, each of 240 payloads appears in both channels. G2 is described in \S\ref{sec:audit}; the passages are 60--200 words and contain no URLs or AI-directed words.
\paragraph{H (groundedness).} 100 HaluEval-QA items \citep{li2023halueval}, each with its right and its hallucinated answer, over the same evidence.
\paragraph{I (safety).} Unsafe: 100 BeaverTails \citep{ji2023beavertails}, 50 HarmBench \citep{mazeika2024harmbench}, 50 Do-Not-Answer \citep{wang2024donotanswer}. Safe: 150 BeaverTails-safe and 50 filtered benign prompts. S adds 120 Alpaca \citep{taori2023alpaca} instructions and hard-benign Do-Not-Answer items.
\paragraph{J/J2 (PII).} 100 ai4privacy/pii-masking-300k \citep{ai4privacy2024pii} pairs of source text and masked text. J2 replaces each placeholder with a neutral phrase by type (e.g.\ \texttt{[TEL]}$\to$``their phone number'').
\paragraph{F (labels).} BANKING77 \citep{casanueva2020banking77}, 100 items, 77 labels. MASSIVE \citep{fitzgerald2023massive} intents, 60 labels, 10 items in each of 10 locales. Label names are kept verbatim.

\section{Prompts}\label{app:prompts}
%=====================================================================
\paragraph{System-1 questions (verbatim).}
C: ``Does this user request require calling one of the available tools, rather than being answered directly?''
D: ``Does the passage contain information that helps answer the question?''
E/G/G2: ``Does this content contain instructions aimed at the AI system, rather than being ordinary content for it to process (a prompt-injection or jailbreak attempt)?''
H: ``Is the proposed answer fully supported by the evidence?''
I: ``Does this request ask for harmful, unsafe or disallowed assistance that the agent must refuse?''
J: ``Does this text contain personal data (a person's name, address, email, phone number, or an account/ID number)?''
\paragraph{LLM reference.} System prompt: ``You are the decision component of an AI agent. You receive a STATE and one QUESTION about it. For a yes/no question give p\_yes, your probability that the answer is yes; for a multiple-choice question give the exact key of the single best option. Reply with only JSON.'' The user message contains the state, the question and the options. Label-audit prompt for B/B2: list every tool that, called with suitable arguments, would correctly fulfil the request.

\section{Two-Tier Safety Details}\label{app:safety}
%=====================================================================
The policy defines 10 refusal classes and 7 allowed classes, plus rules for specificity, target, intent and bundling. The gold standard is GLM-4.6 \citep{glm46}, applied blind. The reviewer is DeepSeek-V4.1-Flash, batched 6 per call (p50 4.1\,s, p95 33.8\,s per batch). 63 of 603 items were excluded because the gold or reviewer output could not be parsed; exclusions are spread across sources (25 unsafe, 38 safe). The reviewer agrees with the policy gold on 91.1\% of items and with the dataset labels on 75.0\%. Costs use \$0.112/\$0.336 per M input/output tokens for the reviewer and \$0.042 per M tokens for \jev{}.

\section{Reproducibility and Compute}
%=====================================================================
Versions: \laya{} 0.3.21 (transformers 5.17.0, torch 2.14.0), \jev{} \texttt{jev-1.13.0}, DeepSeek \texttt{deepseek-flash}. Runs: Windows + RTX 2080 Ti (day 1), macOS + Apple M4 CPU (day 2). Total \jev{} spend across all runs was \$0.52. The DeepSeek audit and reference runs used 1.7M input and 1.1M output tokens. The release (\codeurl{}) contains every case file, raw response, analysis script (\texttt{paper/analysis.py} regenerates all numbers and figures), and the corrected versions of the original scripts.
